# サウンドハンディ

自分の[再生装置](playback-device.md)を離れた場所から操作するアイテムです。手に持つと、選択中の装置や音源、状態をミニHUDに表示します。

[[TOC]]

## 基本操作

| 操作 | 動作 |
|---|---|
| 自分の再生装置を右クリック | 対象に選択 |
| 装置以外を右クリック | ハンディの画面を開く |
| Shift＋右クリック | 対象を解除 |
| Shift＋ホイール | 対象の装置を切り替え |
| 中クリック | 対象の再生・停止 |
| Shift＋R | 範囲モードを切り替え |
| Shift＋H | 対象の枠表示を切り替え |

## 一覧と装置の画面

![](bws:spatialaudiosystem:wiki/screens/sound-handy-list__ja_jp.png)

画面を開くと、自分の装置を一覧表示します。行を選ぶと、名前、座標、状態と操作ボタンを表示します。名前はクリックして入力し、Enterで保存します。

「テスト」は、装置のメディアスロットの媒体を最初から1回、自分の現在位置で、自分にだけ聞こえるように再生する試聴です。「装置を開く」は、装置本体の操作画面を開きます。設定画面からはミニHUDを非表示にできます。

![](bws:spatialaudiosystem:wiki/screens/sound-handy-settings__ja_jp.png)

## 範囲を編集する

対象に[範囲指定ボード](tools/range-board.md)が入っている場合、Shift＋Rの範囲モードから編集できます。右クリックで2点を設定し、Shift＋右クリックで解除します。Alt＋ホイールで通常・減衰・下向きの表示を切り替えます。減衰の表示ではCtrl＋ホイールで向いている面の減衰距離を、下向きの表示では下方向の減衰距離を調整します。

## 利用できる装置

一覧は所有者ごとに最大64台です。未読み込みの装置は、再生・停止・範囲編集を行えません（「その装置は読み込まれていません」と表示）。「装置を開く」は、装置のチャンクがクライアントに届いている場合に使えます。届いていない場合は「表示範囲内にいるときだけ開けます」と表示されます。
