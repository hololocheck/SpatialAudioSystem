# サウンドハンディ

自分の [再生装置](playback-device.md) を離れた場所から扱うアイテムです。装置を設置した人、または装置を最初に開いた人がその装置の所有者になり、ハンディにはその所有者の装置だけが並びます。

[[TOC]]

## 持ち方

| 操作 | 動き |
|---|---|
| 右クリック（何もない所・装置以外のブロック） | ハンディ画面を開く |
| 右クリックで自分の再生装置 | その装置を対象にする |
| Shift + 右クリック | 対象を解除 |
| Shift + ホイール | 対象の装置を一覧から順に切替 |
| 中ボタン | 対象の装置を再生 / 停止（記録媒体が入っているとき） |
| Shift + R | 範囲モードのトグル（下記） |
| Shift + H | ハイライトのトグル: 対象の装置の枠がブロック越しに見える |

## ミニ HUD

ハンディを持っている間、画面の左下に小さなパネルが左からスライドインします。上から、対象の装置（再生装置のアイコン・名前・n / N）、入っている記録媒体（形式ごとの色のアイコンとファイル名。無ければ「再生できない」）、状態（再生中 / 停止中）、範囲モード（Shift + R。ボードが無ければ「範囲編集できない」）、ハイライト（Shift + H）の ON / OFF です。Shift + ホイールで対象を切り替えると、パネルの中で行がホイールの向きにスライドして入れ替わります。再生の終わりや媒体の出し入れはサーバーが装置の変化を見て送るので、持ち直さなくても追従します。表示は画面の「設定」で OFF にできます。

## 範囲モード（Shift + R）

対象の装置の範囲を表示します。装置に [範囲指定ボード](tools/range-board.md) が入っていれば、ボードを手に持ったときと同じ操作で装置内のボードを編集できます。

| 操作 | 動き |
|---|---|
| 右クリック（ブロック / 何もない所） | 箱の 1 点目 → 2 点目 |
| Shift + 右クリック | 箱を解除 |
| Alt + ホイール | 表示モード（通常 / 減衰 / 下向き）の切替 |
| Ctrl + ホイール | 向いている面の減衰距離（減衰モードのとき。ボードの HUD にもこの操作が出ます） |

ボードが入っていない装置では編集できません（HUD に「範囲編集できない」）。範囲モードでは範囲指定ボードの設定 HUD が同じ内容で出て、ミニ HUD もそのまま残ります。

## 画面

右下に開く小さなパネルです（下からスライドイン）。開いたときはいつも一覧です。

- **一覧**: 自分の装置。再生装置のアイコン、名前と座標、右端の点が状態（緑=記録媒体あり、赤=記録媒体なし、暗=未読み込み）。行をクリックするとその装置のページが左からスライドインします（← でスライドアウト）。
- **装置**（一覧の行から）: 名前（クリックで編集、Enter で保存）、座標、状態と、再生 / 停止 / テスト / テスト停止 / 装置を開く。← で一覧に戻ります。
  - **テスト**は装置の媒体を自分にだけ、今いる場所で鳴らします（他のプレイヤーには聞こえません）。
  - **装置を開く**は装置本体の画面をその場で開きます。装置のチャンクが自分のクライアントに届いているときだけ使えます。
- **設定**: ミニ HUD の表示。

装置の名前は再生装置の画面でも付けられます（題名の欄をクリック）。

## 制限

- 装置は所有者ごとに 64 台まで一覧に載ります。
- 未読み込み（チャンクが読み込まれていない）の装置は再生・停止・開く・範囲編集ができません。
- 「装置を開く」はチャンクが届いている装置に限ります（画面が装置の情報をクライアント側から読むため）。
