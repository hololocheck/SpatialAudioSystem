# 範囲指定ボード

音が聞こえる空間と、方向ごとの減衰距離を設定するアイテムです。設定後、[再生装置](playback-device.md)の範囲スロットに入れます。

[[TOC]]

## 範囲を決める

手に持って一方の地点を右クリックし、反対側の地点を右クリックします。地点は視線の先64ブロックまで指定できます。2点を対角とする直方体が再生範囲になります。Shift＋右クリックで解除できます。画面下部のHUDで、現在の設定を確認してください。

## 減衰を調整する

Alt＋ホイールで「通常範囲指定」「減衰率設定」「下向き設定」を切り替えます。減衰では、音が弱まる距離をブロック数で調整します。「減衰率設定」では向いている方向、「下向き設定」では下方向の距離を、Ctrl＋ホイールで0〜15ブロックに設定します。初期値は各方向8ブロックです。範囲の枠を確認するときは、再生装置の「範囲表示」を有効にします。
