# レッドストーン出力

![](bws:spatialaudiosystem:wiki/screens/playback-device-redstone__ja_jp.png)

[再生装置](../playback-device.md) の再生に合わせて**レッドストーン信号**を出す設定です。鳴っている間ランプを点けたり、鳴り始め・止められた時・鳴り終わった時にパルスを出して、ドアやピストン、別の回路を動かせます。

[[TOC]]

## 開き方

1. [再生装置](../playback-device.md) を右クリックして開く
2. ▶ ■ ↻ の並びの右にある**レッドストーン**ボタン（赤い枠）をクリック → 本体の横に設定画面が開く

## 操作

| やりたいこと | 操作 |
|---|---|
| 出力を有効にする | 右上の**出力**トグル（全体スイッチ。OFF の間はどのルールも信号を出しません） |
| ルールを追加する | **「＋ エントリ追加」**（最大 16 本） |
| 条件を変える | **条件**の上でホイール: 再生中 / 開始時 / 停止時 / 終了時 |
| 信号の強さ | **強度**の上でホイール（1〜15） |
| 遅らせる | **遅延**の上でホイール（0.5 秒刻み、最大 30 秒） |
| パルスの長さ | **長さ**の上でホイール（0.1 秒刻み、最大 5 秒。条件が「再生中」のときは使いません） |
| 反応するエントリ | **対象**の上でホイール: 全体（単体再生も含め何が鳴っても）/ #1〜#16（その [スケジュール](schedule.md) エントリだけ） |
| 順番を入れ替える | 行の左の **▲ / ▼** |
| 削除する | 行の **✕** |

> [!TIP]
> 数値の増減に ＋ / − ボタンはありません。**値の上でホイール**が Manta UI 共通の作法です。

## 条件の意味

| 条件 | 出力 |
|---|---|
| 再生中 | 鳴っている間、強度を出し続けます（遅延の分だけ遅れて点き、遅れて消えます） |
| 開始時 | 鳴り始めたときにパルス |
| 停止時 | プレイヤー・レッドストーン・スケジュール・API で止められたときにパルス |
| 終了時 | 音声が最後まで鳴り終わったときにパルス |

いくつものルールが同時に有効なときは、**いちばん強い**ものが出力されます。信号は装置のすべての面から弱い動力として出るので、隣に置いたレッドストーンの粉・ランプ・リピーター・ピストンに届きます。
