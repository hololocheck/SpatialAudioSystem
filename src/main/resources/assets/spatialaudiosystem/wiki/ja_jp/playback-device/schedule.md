# ♪スケジュール

![](bws:spatialaudiosystem:wiki/screens/playback-device-schedule__ja_jp.png)

[再生装置](../playback-device.md) で**複数の記録媒体を順番に**鳴らすための編集画面です。再生装置の **♪スケジュール**ボタンで開きます。

[[TOC]]

## 開き方

1. [再生装置](../playback-device.md) を右クリックして開く
2. **♪スケジュール**ボタンをクリック → 本体の横にスケジュール画面が開く
3. 開いているあいだもプレイヤーインベントリは操作できます（媒体をドラッグで入れられます）

## 操作

| やりたいこと | 操作 |
|---|---|
| エントリを追加する | **「＋ エントリ追加」**をクリック |
| 音声を割り当てる | インベントリから記録媒体を**行の右端のスロット**へドラッグ |
| 再生回数を変える | 行の**回数表示（×N）にカーソルを合わせてホイール** |
| 順番を入れ替える | 行の左にある **▲ / ▼** |
| その行だけ試聴する | 行の **▶** |
| エントリを削除する | 行の **✕**（入っていた媒体は手元に戻ります） |
| 全部を順に鳴らす | **「▶ 連続再生」** |
| 止める | **■** |

> [!TIP]
> 数値の増減に ＋ / − ボタンはありません。**値の上でホイール**が Manta UI 共通の作法です。

> [!NOTE]
> 連続再生では、各エントリをその**再生回数だけ繰り返してから**次のエントリへ進みます。音声が空の行は読み飛ばされます。

## 再生中の表示

いま鳴っているエントリの行は**枠がハイライト**され、進行に合わせて移動します。

## 制限

| 項目 | 値 |
|---|---|
| エントリ数 | 最大 6 |
| 再生回数 | 1 〜 10 |
