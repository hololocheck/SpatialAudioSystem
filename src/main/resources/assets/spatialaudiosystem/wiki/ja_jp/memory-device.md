# 記憶装置

![](bws:spatialaudiosystem:wiki/screens/memory-device__ja_jp.png)

PC 上の音声ファイルを**記録媒体**に書き込むブロックです。書き込みが終わった媒体は [再生装置](playback-device.md) で鳴らせます。

[[TOC]]

## 開き方

1. **記憶装置**を設置する
2. **右クリック**で GUI を開く
3. 最初に開いた人が**オーナー**になります（顔アイコンで公開 / 非公開を切替）

## 操作

| やりたいこと | 操作 |
|---|---|
| 音声ファイルを選ぶ | **「ファイル選択」ボタン**をクリック → OS のファイルダイアログが開く |
| 記録媒体を入れる | 空の記録媒体を**入力スロット**へ |
| 書き込む | **●** をクリック。矢印バーが進み、終わると完成品スロットへ移動する |
| 選択を取り消す | **×** をクリック |
| 試聴する | **▶ / ■**（完成品があればそれを、無ければ選択中のファイルを再生 / 停止） |
| 公開 / 非公開 | 右下の**顔アイコン**をクリック |

> [!NOTE]
> 対応形式は **mp3 / ogg / wav** です。1 ファイルあたりのサイズ上限があり、超えるファイルは読み込まれません。

## 画面の見かた

| 要素 | 内容 |
|---|---|
| ジャケット | 音声に埋め込まれたアートワーク。無い場合は記録媒体アイコン |
| 状態 | 準備完了 / 書込中 / 失敗理由 |
| ファイル・形式・長さ | 完成品があればその情報、無ければ選択中ファイルの情報 |
| 入力スロット | 空の記録媒体を入れる |
| 完成品スロット | 書き込み済みの記録媒体が出てくる |

> [!TIP]
> ジャケットは**書き込んだ瞬間から**表示されます。mp3 に埋め込まれたアートワークが自動で取り込まれ、完成品を取り出すと表示も消えます。

## 書き込めないとき

| 表示 | 意味 |
|---|---|
| 記録媒体を入れてください | 入力スロットが空 |
| 音声ファイルを選択してください | ファイルが未選択 |
| 完成品を取り出してください | 完成品スロットが埋まっている |
