# 記憶装置

![](bws:spatialaudiosystem:wiki/screens/memory-device__ja_jp.png)

PC内の音声ファイルを、記録媒体へ書き込む設備です。設置して右クリックすると画面が開きます。

[[TOC]]

## 書き込む

1. 「ファイル選択」でMP3・OGG・WAVのファイルを選びます。上限は1ファイル10MBです。
2. 入力スロットに、空の記録媒体を入れます。
3. 書き込みボタンを押します。
4. 進捗が完了したら、出力スロットから媒体を取り出します。

×で選択を取り消せます。再生・停止ボタンでは、出力スロットに媒体があればその音源、なければ選択中の音源を試聴します。

画面にはファイル名、形式、長さ、状態を表示します。MP3にジャケット画像が埋め込まれている場合は、その画像も取り込みます。画像がない場合は媒体のアイコンを表示します。

## 書き込めないとき

| 表示 | 確認すること |
|---|---|
| 記録媒体を入れてください | 入力スロットに空の媒体があるか |
| 音声ファイルを選択してください | ファイルを選んだか |
| 完成品を取り出してください | 出力スロットが空いているか |

対応形式とファイル容量もご確認ください。最初に画面を開いたプレイヤーが所有者になり、アクセス権は顔アイコンから切り替えられます。
