# Spatial Audio System

手持ちの音声ファイルを**ワールド内で鳴らす**ための MOD です。音声を記録媒体に書き込み、再生装置から範囲を指定して鳴らします。発車メロディ、館内放送、BGM などに使えます。

[[TOC]]

## 構成要素

| 要素 | 役割 |
|---|---|
| [記憶装置](memory-device.md) | PC 上の音声ファイル (mp3 / ogg / wav) を**記録媒体**に書き込むブロック |
| 記録媒体 | 音声を保持するアイテム。再生装置に入れて鳴らす |
| [再生装置](playback-device.md) | 記録媒体を鳴らすブロック。単体再生と [♪スケジュール](playback-device/schedule.md) による連続再生 |
| [範囲指定ボード](tools/range-board.md) | 音が聞こえる範囲と減衰を決めるアイテム |

## 基本の流れ

1. **記憶装置**を設置して右クリック → 「ファイル選択」で音声を選ぶ
2. 空の**記録媒体**を入力スロットに入れ、書き込みボタンを押す
3. 完成した記録媒体を**再生装置**のメディアスロットへ
4. **範囲指定ボード**で範囲を決め、再生装置の範囲スロットに入れる
5. **▶** で再生。複数を順に鳴らすなら [♪スケジュール](playback-device/schedule.md)

> [!NOTE]
> 音声ファイルの実体はサーバー側に保存され、再生時に各クライアントへ配信されます。記録媒体アイテムが持つのはファイル本体ではなく参照 ID です。そのため媒体を複製しても容量は増えません。

## ヒントと F1

各画面の右上にある **Hint トグル**を ON にすると、要素にカーソルを合わせたとき画面左下に説明が出ます。その状態で **F1** を押すと、その機能の解説ページが開きます。**📖** ボタンからは、その画面の解説ページを直接開けます。

## 管理モード (公開 / 非公開)

装置を最初に開いた人が**オーナー**になります。顔アイコンをクリックすると**公開（緑）/ 非公開（赤）**が切り替わり、非公開のあいだはオーナー以外が開けません。
