# Spatial Audio System

手持ちの音声ファイルをワールドに取り込み、聞こえる範囲や再生方法を設定するModです。発車メロディ、館内放送、BGMなどに使えます。

[[TOC]]

## 音を流すまでの手順

1. [記憶装置](memory-device.md)を右クリックし、「ファイル選択」で音声を選びます。
2. 空の記録媒体を入力スロットに入れ、書き込みます。
3. 完成した媒体を、[再生装置](playback-device.md)のメディアスロットへ入れます。
4. 必要に応じて、範囲を設定した[ボード](tools/range-board.md)を範囲スロットへ入れます。
5. 再生ボタンを押します。複数の音源は[スケジュール](playback-device/schedule.md)で設定できます。

音源はサーバーに保存され、再生時に各プレイヤーへ配信します。記録媒体は、その音源を参照するIDを保持します。

## 操作のヒント

画面の「ヒント」を有効にすると、カーソルを合わせた項目の説明を表示します。F1で該当機能の解説、Wikiボタンでその画面の解説を開けます。

装置は顔アイコンから公開・非公開を切り替えられます。共同で操作する設備か、所有者だけが操作する設備かに合わせて選んでください。
