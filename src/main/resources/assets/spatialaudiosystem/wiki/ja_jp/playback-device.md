# 再生装置

![](bws:spatialaudiosystem:wiki/screens/playback-device__ja_jp.png)

[記憶装置](memory-device.md) で書き込んだ記録媒体を鳴らすブロックです。1 枚だけ鳴らす**単体再生**と、複数を順番に鳴らす [♪スケジュール](playback-device/schedule.md) があります。

[[TOC]]

## 開き方

1. **再生装置**を設置して**右クリック**
2. 最初に開いた人が**オーナー**になります

## 操作

| やりたいこと | 操作 |
|---|---|
| 単体で鳴らす | 記録媒体を**メディアスロット**に入れ、**▶** をクリック |
| 止める | **■** をクリック（単体・スケジュールのどちらも止まります） |
| 範囲を設定する | [範囲指定ボード](tools/range-board.md) を**範囲スロット**に入れる |
| 減衰を切り替える | **Attenuate トグル** |
| 範囲を見えるようにする | **Show Range トグル** |
| 連続再生を組む | **スケジュールトグルを ON** → **♪スケジュール**ボタン → [スケジュール画面](playback-device/schedule.md) |
| 公開 / 非公開 | 右端の**顔アイコン**をクリック |

## 画面の見かた

| 要素 | 内容 |
|---|---|
| ジャケット | メディアスロットに入っている音声のアートワーク |
| 状態 | 再生中 / 停止 |
| ファイル・形式 | メディアスロットの記録媒体の情報 |
| 範囲スロット（左） | [範囲指定ボード](tools/range-board.md) を入れる |
| メディアスロット | 単体再生する記録媒体を入れる |
| ♪スケジュール | 連続再生の編集画面を開く |

> [!TIP]
> 範囲スロットが空でも音は鳴りますが、その場合は既定の減衰しかかかりません。狙った範囲だけに響かせたいときは [範囲指定ボード](tools/range-board.md) を入れてください。

> [!NOTE]
> **■（停止）はひとつで両方に効きます。** 単体再生でも [♪スケジュール](playback-device/schedule.md) の連続再生でも、これを押せば止まります。

> [!NOTE]
> **スケジュールトグルが ON のあいだ、メディアスロットは ✕ 表示になり使えません。** 記録媒体のシフトクリックはスケジュールの空き行に入り、**▶ も連続再生の開始として動作**します。OFF に戻すと通常の単体再生に戻ります。
